Found a bug in Auzonix? Thank you for helping us improve the project!
When reporting a bug, please provide the following information:
## 1. Bug Description
Describe the problem you encountered. What seems to be wrong?
## 2. Steps to Reproduce
Provide the steps that led to the problem.
Try to describe them in the order they occurred so that the issue can be reproduced.
## 3. Actual and Expected Behavior
- **Expected Behavior:** What did you expect to happen?
- **Actual Behavior:** What happened instead?
## 4. System Logs
If possible, attach relevant system logs or error messages.
They can help identify the source of the problem.
## 5. Possible Solution (Optional)
If you have an idea about how to fix the issue, feel free to share it!
Your suggestion is welcome, but it is not required.
